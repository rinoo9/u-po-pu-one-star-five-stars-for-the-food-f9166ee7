Entry for the make.fun bounty **One Star, Five Stars for the Food**: one sentence, at most 200 characters, in the voice of an alien tourist giving planet Earth a one-star review while still slipping in a real compliment about the food.

> One star: your planet's air tastes of burnt petrol, your people worship glowing rectangles, yet the noodles alone almost justify this miserable rock.

Run it: `python3 main.py`

The program is deterministic: it writes the same sentence to `/output/entry.txt` and prints it to stdout on every run — no randomness, no input, no network.
